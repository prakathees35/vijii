BIRTHDAY VIJII WEBSITE - NO FOLDER VERSION

There is NO images folder in this version.

Put index.html and your photos directly in the GitHub repository root.

Recommended names:
photo1.jpg
photo2.jpg
photo3.jpg
...
photo18.jpg

The code automatically tries .jpg, .jpeg, .png and .webp, so .jpeg photos are also fine.

Your GitHub repository should look like:
README.md
index.html
photo1.jpeg
photo2.jpeg
photo3.jpg
photo4.jpg
...
photo18.jpg

If a number is missing, that photo card is automatically hidden.

To update GitHub:
1. Open your vijii repository.
2. Click Add file -> Upload files.
3. Upload the new index.html and your photos directly in the root.
4. Commit changes.
5. GitHub Pages will update automatically.

Pages settings:
Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save
