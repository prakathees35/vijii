Birthday Vijii Website

GitHub image setup:
1. Keep index.html and all photo files in the same folder (repository root).
2. Upload your photos directly beside index.html — NO images folder is needed.
3. Name the photos:
   photo1.jpg
   photo2.jpg
   ...
   photo18.jpg
4. The gallery automatically loads photo1.jpg through photo18.jpg from the same folder.

If you replace the photos, keep the same filenames or update the gallery code in index.html.
